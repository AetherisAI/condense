# M0934 — Limit Hardware Installation

- **Type:** mitigation
- **Domain:** ICS ATT&CK
- **ATT&CK URL:** https://attack.mitre.org/mitigations/M0934
- **Last modified:** 2025-04-16

## Description

Block users or groups from installing or using unapproved hardware on systems, including USB devices.

## Techniques addressed

- **T0847 Replication Through Removable Media** — Enforce system policies or physical restrictions to limit hardware such as USB devices on critical assets.
