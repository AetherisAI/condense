# T1003.004 — OS Credential Dumping: LSA Secrets

- **Type:** sub-technique of T1003 OS Credential Dumping
- **Domain:** Enterprise ATT&CK
- **Tactics:** Credential Access
- **Platforms:** Windows
- **ATT&CK URL:** https://attack.mitre.org/techniques/T1003/004
- **Last modified:** 2025-10-24

## Description

Adversaries with SYSTEM access to a host may attempt to access Local Security Authority (LSA) secrets, which can contain a variety of different credential materials, such as credentials for service accounts. LSA secrets are stored in the registry at `HKEY_LOCAL_MACHINE\SECURITY\Policy\Secrets`. LSA secrets can also be dumped from memory.

Reg can be used to extract from the Registry. Mimikatz can be used to extract secrets from memory.

## Mitigations

- **M1017 User Training** — Limit credential overlap across accounts and systems by training users and administrators not to use the same password for multiple accounts.
- **M1026 Privileged Account Management** — Follow best practices for design and administration of an enterprise network to limit privileged account use across administrative tiers.
- **M1027 Password Policies** — Ensure that local administrator accounts have complex, unique passwords across all systems on the network.

## Detection strategies

- **DET0437 Detection of LSA Secrets Dumping via Registry and Memory Extraction**
  - AN1212 (Windows): Detects adversary activity aimed at accessing LSA Secrets, including registry key export of HKEY_LOCAL_MACHINE\SECURITY\Policy\Secrets or memory scraping via tools such as Mimikatz or PowerSploit's Invoke-Mimikatz. Log sources: WinEventLog:Security (EventCode=4663, 4670, 4656); WinEventLog:Sysmon (EventCode=1); WinEventLog:Sysmon (EventCode=10); WinEventLog:Sysmon (EventCode=7).

## Procedure examples

- **C0064 AI-Assisted Breach of Mexico's Government Infrastructure** (campaign) — During the AI-Assisted Breach of Mexico's Government Infrastructure, the adversary requested Claude Code to utilize secretsdump to obtain LSA secrets.
- **G0004 Ke3chang** (group) — Ke3chang has dumped credentials, including by using gsecdump.
- **G0016 APT29** (group) — APT29 has used the `reg save` command to extract LSA secrets offline.
- **G0027 Threat Group-3390** (group) — Threat Group-3390 actors have used gsecdump to dump credentials. They have also dumped credentials from domain controllers.
- **G0035 Dragonfly** (group) — Dragonfly has dropped and executed SecretsDump to dump password hashes.
- **G0045 menuPass** (group) — menuPass has used a modified version of pentesting tools wmiexec.vbs and secretsdump.py to dump credentials.
- **G0049 OilRig** (group) — OilRig has used credential dumping tools such as LaZagne to steal credentials to accounts logged into the compromised system and to Outlook Web Access.
- **G0064 APT33** (group) — APT33 has used a variety of publicly available tools like LaZagne to gather credentials.
- **G0069 MuddyWater** (group) — MuddyWater has performed credential dumping with LaZagne.
- **G0077 Leafminer** (group) — Leafminer used several tools for retrieving login and password information, including LaZagne.
- **G1003 Ember Bear** (group) — Ember Bear has used frameworks such as Impacket to dump LSA secrets for credential capture.
- **S0002 Mimikatz** (software) — Mimikatz performs credential dumping to obtain account and password information useful in gaining access to additional systems and enterprise network resources. It contains functionality to acquire information about credentials in many ways, including from the LSA.
- **S0008 gsecdump** (software) — gsecdump can dump LSA secrets.
- **S0050 CosmicDuke** (software) — CosmicDuke collects LSA secrets.
- **S0192 Pupy** (software) — Pupy can use Lazagne for harvesting credentials.
- **S0349 LaZagne** (software) — LaZagne can perform credential dumping from LSA secrets to obtain account and password information.
- **S0357 Impacket** (software) — SecretsDump and Mimikatz modules within Impacket can perform credential dumping to obtain account and password information.
- **S0488 CrackMapExec** (software) — CrackMapExec can dump hashed passwords from LSA secrets for the targeted system.
- **S0677 AADInternals** (software) — AADInternals can dump secrets from the Local Security Authority.
- **S1022 IceApple** (software) — IceApple's Credential Dumper module can dump LSA secrets from registry keys, including: `HKLM\SECURITY\Policy\PolEKList\default`, `HKLM\SECURITY\Policy\Secrets\*\CurrVal`, and `HKLM\SECURITY\Policy\Secrets\*\OldVal`.
