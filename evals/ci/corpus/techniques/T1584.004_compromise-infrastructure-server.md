# T1584.004 — Compromise Infrastructure: Server

- **Type:** sub-technique of T1584 Compromise Infrastructure
- **Domain:** Enterprise ATT&CK
- **Tactics:** Resource Development
- **Platforms:** PRE
- **ATT&CK URL:** https://attack.mitre.org/techniques/T1584/004
- **Last modified:** 2026-09-18

## Description

Adversaries may compromise third-party servers that can be used during targeting. Use of servers allows an adversary to stage, launch, and execute an operation. During post-compromise activity, adversaries may utilize servers for various tasks, including for Command and Control. Instead of purchasing a Server or Virtual Private Server, adversaries may compromise third-party servers in support of operations.

Adversaries may also compromise web servers to support watering hole operations, as in Drive-by Compromise, or email servers to support Phishing operations.

## Mitigations

- **M1056 Pre-compromise** — This technique cannot be easily mitigated with preventive controls since it is based on behaviors performed outside of the scope of enterprise defenses and controls.

## Detection strategies

- **DET0874 Detection of Server**
  - AN2006 (PRE): Once adversaries have provisioned software on a compromised server (ex: for use as a command and control server), internet scans may reveal servers that adversaries have compromised. Consider looking for identifiable patterns such as services listening, certificates in use, SSL/TLS negotiation features, or other response artifacts associated with adversary C2 software. Much of this activity will take place outside the visibility of the target organization, making detection of this behavior difficult. Detection efforts may be focused on related stages of the adversary lifecycle, such as during Command and Control. Log sources: Internet Scan (None); Internet Scan (None).

## Procedure examples

- **C0002 Night Dragon** (campaign) — During Night Dragon, threat actors compromised web servers to use for C2.
- **C0013 Operation Sharpshooter** (campaign) — For Operation Sharpshooter, the threat actors compromised a server they used as part of the campaign's infrastructure.
- **C0022 Operation Dream Job** (campaign) — For Operation Dream Job, Lazarus Group compromised servers to host their malicious tools.
- **C0042 Outer Space** (campaign) — During Outer Space, OilRig compromised an Israeli human resources site to use as a C2 server.
- **C0044 Juicy Mix** (campaign) — During Juicy Mix, OilRig compromised an Israeli job portal to use for a C2 server.
- **C0062 Anthropic AI-orchestrated Campaign** (campaign) — During the Anthropic AI-orchestrated Campaign, the adversary operated dedicated penetration testing servers accessible via MCP to support remote command execution, simultaneous tool coordination, and persistent operational state maintenance across campaign sessions.
- **G0010 Turla** (group) — Turla has used compromised servers as infrastructure.
- **G0023 APT16** (group) — APT16 has compromised otherwise legitimate sites as staging servers for second-stage payloads.
- **G0032 Lazarus Group** (group) — Lazarus Group has compromised servers to stage malicious tools.
- **G0034 Sandworm Team** (group) — Sandworm Team compromised legitimate Linux servers running the EXIM mail transfer agent for use in subsequent campaigns.
- **G0035 Dragonfly** (group) — Dragonfly has compromised legitimate websites to host C2 and malware modules.
- **G0065 Leviathan** (group) — Leviathan has used compromised legitimate websites as command and control nodes for operations.
- **G0119 Indrik Spider** (group) — Indrik Spider has served fake updates via legitimate websites that have been compromised.
- **G1006 Earth Lusca** (group) — Earth Lusca has used compromised web servers as part of their operational infrastructure.
- **G1017 Volt Typhoon** (group) — Volt Typhoon has used compromised Paessler Router Traffic Grapher (PRTG) servers from other organizations for C2.
- **G1034 Daggerfly** (group) — Daggerfly compromised web servers hosting updates for software as part of a supply chain intrusion.
