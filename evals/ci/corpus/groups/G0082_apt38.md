# G0082 — APT38

- **Type:** group
- **Domain:** Enterprise ATT&CK, ICS ATT&CK
- **Also known as:** NICKEL GLADSTONE, BeagleBoyz, Bluenoroff, Stardust Chollima, Sapphire Sleet, COPERNICIUM
- **ATT&CK URL:** https://attack.mitre.org/groups/G0082
- **Last modified:** 2026-10-09

## Description

APT38 is a North Korean state-sponsored threat group that specializes in financial cyber operations; it has been attributed to the Reconnaissance General Bureau. Active since at least 2014, APT38 has targeted banks, financial institutions, casinos, cryptocurrency exchanges, SWIFT system endpoints, and ATMs in at least 38 countries worldwide. Significant operations include the 2016 Bank of Bangladesh heist, Bancomext and Banco de Chile, along with software supply chain compromises and destructive malware attacks.

North Korean group definitions are known to have significant overlap, and some security researchers report all North Korean state-sponsored cyber activity under the name Lazarus Group instead of tracking clusters or subgroups.

## Techniques used

- **T1005 Data from Local System** — APT38 has collected data from a compromised host.
- **T1012 Query Registry** — APT38 has run node.js malware to query the Registry to discover installed software.
- **T1027.002 Obfuscated Files or Information: Software Packing** — APT38 has used several code packing methods such as Themida, Enigma, VMProtect, and Obsidium, to pack their implants.
- **T1027.010 Obfuscated Files or Information: Command Obfuscation** — APT38 has utilized Base64 encoded PowerShell scripts.
- **T1027.015 Obfuscated Files or Information: Compression** — APT38 has compressed its malicious payloads in ZIP files for delivery to victims.
- **T1027.016 Obfuscated Files or Information: Junk Code Insertion** — APT38 has added thousands of blank lines to scripts to push malicious logic past the scrollable view of the script editor.
- **T1033 System Owner/User Discovery** — APT38 has identified primary users, currently logged in users, sets of users that commonly use a system, or inactive users. APT38 has run malware to enumerate the current user on compromised hosts.
- **T1036.003 Masquerading: Rename Legitimate Utilities** — APT38 has renamed system utilities, such as `rundll32.exe` and `mshta.exe`, to avoid detection.
- **T1036.005 Masquerading: Match Legitimate Resource Name or Location** — APT38 has named malicious payloads as benign-looking executables to blend in the environment including Run keys, npm packages, and JavaScript utilities often using names mirroring Apple, Windows, or other native system files.
- **T1036.006 Masquerading: Space after Filename** — APT38 has put several spaces before a file extension to avoid detection and suspicion.
- **T1036.008 Masquerading: Masquerade File Type** — APT38 has configured malware to rename malicious payloads with naming conventions that reduce a chance of detection to include renaming “package.md” to “package.json”.
- **T1041 Exfiltration Over C2 Channel** — APT38 has exfiltrated victim device and user details contained in a POST request to register the compromised system with C2 infrastructure.
- **T1048.002 Exfiltration Over Alternative Protocol: Exfiltration Over Asymmetric Encrypted Non-C2 Protocol** — APT38 has used malware to exfiltrate stolen data with a custom ICAP-style protocol over HTTPS.
- **T1049 System Network Connections Discovery** — APT38 installed a port monitoring tool, MAPMAKER, to print the active TCP connections on the local system.
- **T1053.003 Scheduled Task/Job: Cron** — APT38 has used cron to create pre-scheduled and periodic background jobs on a Linux system.
- **T1053.005 Scheduled Task/Job: Scheduled Task** — APT38 has used Task Scheduler to run programs at system startup or on a scheduled basis for persistence. Additionally, APT38 has used living-off-the-land scripts to execute a malicious script via a scheduled task.
- **T1053.006 Scheduled Task/Job: Systemd Timers** — APT38 has used a multiplatform implant that can write to `~/.config/systemd/nvmconf/` to gain persistence on Linux hosts.
- **T1055 Process Injection** — APT38 has injected malicious payloads into the `explorer.exe` process. APT38 has also injected malicious binaries directly into memory on compromised hosts.
- **T1056.001 Input Capture: Keylogging** — APT38 used a Trojan called KEYLIME to capture keystrokes from the victim’s machine.
- **T1056.002 Input Capture: GUI Input Capture** — APT38 has leveraged a fictitious native macOS password dialog prompt to entice victims to enter credentials.
- **T1057 Process Discovery** — APT38 leveraged Sysmon to understand the processes, services in the organization. APT38 has used Python versions of its remote access tools on Linux targets. APT38 has also configured malicious payloads to gather running processes using `ps aux`.
- **T1059.001 Command and Scripting Interpreter: PowerShell** — APT38 has used PowerShell to execute commands and other operational tasks. APT38 has also used PowerShell to establish persistence and establish C2 communication on compromised hosts.
- **T1059.002 Command and Scripting Interpreter: AppleScript** — APT38 has sent Mac users.scpt files to trigger malicious downloads. APT38 has targeted macOS uses with native script stagers leading to malicious paylaods. APT38 has also used an AppleScript-based credential harvesting component.
- **T1059.003 Command and Scripting Interpreter: Windows Command Shell** — APT38 has used a command-line tunneler, NACHOCHEESE, to give them shell access to a victim’s machine. Additionally, APT38 has used batch scripts. APT38 has also executed scripts to launch `cmd.exe` to POST stolen data to actor-controlled domains.
- **T1059.004 Command and Scripting Interpreter: Unix Shell** — APT38 has run malicious payloads using Linux and Unix shells. APT38 has also executed Unix commands sequentially using `&&` and in the background with `&`.
- **T1059.005 Command and Scripting Interpreter: Visual Basic** — APT38 has used VBScript to execute commands and other operational tasks. APT38 has sent Windows victims Visual Basic script stagers leading to malicious downloads. APT38 has also used VBScript to execute scripts for data exfiltration.
- **T1059.006 Command and Scripting Interpreter: Python** — APT38 has used Python versions of its remote access tools on Linux targets.
- **T1059.007 Command and Scripting Interpreter: JavaScript** — APT38 has utilized malicious JavaScript payloads to compromise victims.
- **T1070.003 Indicator Removal: Clear Command History** — APT38 has executed scripts to delete the PowerShell command history file.
- **T1070.004 Indicator Removal: File Deletion** — APT38 has used a utility called CLOSESHAVE that can securely delete a file from the system. APT38 has also removed malware, tools, scripts, or other non-native files used during the intrusion to reduce their footprint or as part of the post-intrusion cleanup process.
- **T1070.006 Indicator Removal: Timestomp** — APT38 has modified data timestamps to mimic files that are in the same folder on a compromised host.
- **T1071.001 Application Layer Protocol: Web Protocols** — APT38 used a backdoor, QUICKRIDE, to communicate to the C2 server over HTTP and HTTPS. APT38 has also configured malicious payloads to communicate with C2 using HTTP POST requests that blend in with common traffic.
- **T1074.001 Data Staged: Local Data Staging** — APT38 has staged files in a central location prior to exfiltration.
- **T1078.003 Valid Accounts: Local Accounts** — APT38 has validated stolen credentials against the local macOS authentication database using directory services prior to exfiltration.
- **T1078.004 Valid Accounts: Cloud Accounts** — APT38 has used victim maintainer accounts for the npm Registry to publish malicious packages.
- **T1082 System Information Discovery** — APT38 has attempted to get detailed information about a compromised host, including the operating system, version, patches, hotfixes, and service packs. APT38 has executed malware to collect current user, host name, system time, and operating system install date from targeted systems.
- **T1083 File and Directory Discovery** — APT38 has enumerated files and directories, or searched in specific locations within a compromised host.
- **T1105 Ingress Tool Transfer** — APT38 used a backdoor, NESTEGG, that has the capability to download and upload files to and from a victim’s machine. Additionally, APT38 has downloaded other payloads onto a victim’s machine. APT38 has also injected npm packages with malicious dependencies that download second-stage payloads to victim machines.
- **T1106 Native API** — APT38 has used the Windows API to execute code within a victim's system.
- **T1110 Brute Force** — APT38 has used brute force techniques to attempt account access when passwords are unknown or when password hashes are unavailable.
- **T1112 Modify Registry** — APT38 uses a tool called CLEANTOAD that has the capability to modify Registry keys.
- **T1115 Clipboard Data** — APT38 used a Trojan called KEYLIME to collect data from the clipboard.
- **T1124 System Time Discovery** — APT38 has run malware to discover the system time on compromised hosts.
- **T1132.001 Data Encoding: Standard Encoding** — APT38 has utilized Base64 encoded HTTP POST communications to C2.
- **T1135 Network Share Discovery** — APT38 has enumerated network shares on a compromised host.
- **T1140 Deobfuscate/Decode Files or Information** — APT38 has used the RC4 algorithm to decrypt configuration data. APT38 has decocoded Base64 encoded PowerShell scripts prior to execution.
- **T1189 Drive-by Compromise** — APT38 has conducted watering holes schemes to gain initial access to victims.
- **T1195.001 Supply Chain Compromise: Compromise Software Dependencies and Development Tools** — APT38 has injected malicious dependencies into software packages such as Axios and Mastra npm packages.
- **T1204.001 User Execution: Malicious Link** — APT38 has used links to execute a malicious Visual Basic script. APT38 has directed users to navigate to a website under adversary control through the sharing of links in messages.
- **T1204.002 User Execution: Malicious File** — APT38 has attempted to lure victims into enabling malicious macros within email attachments. Additionally, APT38 has used malicious Word documents and shortcut files. APT38 has lured victims into opening malicious .scpt or .vbs files to fix fake connection issues with online meetings. APT38 has used social media invites to lure victims into opening malicious files hosted on cloud infrastructure.
- **T1213.005 Data from Information Repositories: Messaging Applications** — APT38 has gathered Telegram Desktop messaging data from the applications data directories stored on the victim device to include cryptographic key material, and session mapping files that can recreate a compromised user’s Telegram session on another system.
- **T1213.006 Data from Information Repositories: Databases** — APT38 has copied Apple Notes database from its application container and staged for upload.
- **T1217 Browser Information Discovery** — APT38 has collected browser bookmark information to learn more about compromised hosts, obtain personal information about users, and acquire details about internal network resources. APT38 has also used malware capable of enumerating 166 unique cryptocurrency wallets, browser extensions, and browser history.
- **T1218.001 System Binary Proxy Execution: Compiled HTML File** — APT38 has used CHM files to move concealed payloads.
- **T1218.005 System Binary Proxy Execution: Mshta** — APT38 has used a renamed version of `mshta.exe` to execute malicious HTML files.
- **T1218.007 System Binary Proxy Execution: Msiexec** — APT38 has used `msiexec.exe` to execute malicious files.
- **T1218.011 System Binary Proxy Execution: Rundll32** — APT38 has used rundll32.exe to execute binaries, scripts, and Control Panel Item files and to execute code via proxy to avoid triggering security tools.
- **T1222.002 File and Directory Permissions Modification: Linux and Mac Permissions** — APT38 has changed file and directory permissions using `chmod 777`.
- **T1480 Execution Guardrails** — APT38 has leveraged file discovery actions to determine if a predetermined file is present prior to execution to prevent redundant execution on a compromised device.
- **T1480.002 Execution Guardrails: Mutual Exclusion** — APT38 has created a mutex to avoid duplicate execution.
- **T1485 Data Destruction** — APT38 has used a custom secure delete function to make deleted files unrecoverable.

- **T1505.003 Server Software Component: Web Shell** — APT38 has used web shells for persistence or to ensure redundant access.
- **T1518 Software Discovery** — APT38 has enumerated installed applications to build an inventory of the system’s software environment.
- **T1518.001 Software Discovery: Security Software Discovery** — APT38 has identified security software, configurations, defensive tools, and sensors installed on a compromised system. APT38 has also executed malware implants to enumerate all installed applications on Windows hosts including installed security products.
- **T1529 System Shutdown/Reboot** — APT38 has used a custom MBR wiper named BOOTWRECK, which will initiate a system reboot after wiping the victim's MBR.
- **T1543.001 Create or Modify System Process: Launch Agent** — APT38 has executed a multiplatform implant that placed launch agents in ~/Library/NodePackages/ to establish persistence on macOS.

- **T1543.004 Create or Modify System Process: Launch Daemon** — APT38 has established persistence through storing the malicious plist files in `/Library/LaunchDaemons`.
- **T1546.016 Event Triggered Execution: Installer Packages** — APT38 has poisoned Axios and Mastra npm packages with malicious post-install hooks.

APT38 has executed a multiplatform implant that dropped a Registry Run key to `:\ProgramData\NodePackages\` for persistence on Windows machines. The edited `TCC.db` file allowed code signing authorization, permission access, etc. without requiring a user prompt.

- **T1552.004 Unsecured Credentials: Private Keys** — APT38 has gathered cryptographic key data related to cryptocurrency wallets, SSH keys, and messaging applications to include Telegram.
- **T1553.005 Subvert Trust Controls: Mark-of-the-Web Bypass** — APT38 has used ISO and VHD files to deploy malware and to bypass Mark-of-the-Web (MOTW) security measures.
- **T1555 Credentials from Password Stores** — APT38 has stolen credentials from the compromised device to include those used to access cryptocurrency wallets.
