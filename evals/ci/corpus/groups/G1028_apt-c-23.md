# G1028 — APT-C-23

- **Type:** group
- **Domain:** Enterprise ATT&CK, Mobile ATT&CK
- **Also known as:** Mantis, Arid Viper, Desert Falcon, TAG-63, Grey Karkadann, Big Bang APT, Two-tailed Scorpion
- **ATT&CK URL:** https://attack.mitre.org/groups/G1028
- **Last modified:** 2026-07-31

## Description

APT-C-23 is a threat group that has been active since at least 2014. APT-C-23 has primarily focused its operations on the Middle East, including Israeli military assets. APT-C-23 has developed mobile spyware targeting Android and iOS devices since 2017.

## Techniques used

- **T1422 System Network Configuration Discovery** — APT-C-23 can collect the victim’s phone number, device information, IMSI, etc.
- **T1655.001 Masquerading: Match Legitimate Name or Location** — APT-C-23 has masqueraded malware as legitimate applications.
- **T1660 Phishing** — APT-C-23 sends malicious links to victims to download the masqueraded application.
